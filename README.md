## 局域网文件传输工具

这是一款浏览器局域网文件传输工具，支持两台设备快速创建连接或加入连接，在同一网络环境下直接互传文件和文本。文件与文本内容均不经过服务器，全部在双方设备之间直接传输，无需担心数据安全性问题。

### 一、连接信息如下：

1. 公网 IP（局域网IP）: 1.204.133.96
2. 连接状态:未连接\已连接
3. 通道状态：未打开、已打开

### 二、主要功能炒作模块

1. 加入连接
   如果创建连接后仍无法看到连接列表，请确认两端页面显示的公网IP是否一致，只有公网IP一致时才可连接。
2. 创建连接
   点击“创建连接”后请保持当前页面停留，不要刷新、关闭或切走页面，等待其它用户加入后系统会自动继续建立连接。
3. 文件接收列表
   超过 10MB、20MB...100MB 的文件浏览器会自动边接收边下载保存，不自动下载的文件接收完成后可手动下载。
4. 文本接收列表
   提供快捷复制功能

### 三、功能说明

该局域网文件传输工具提供“创建连接”“加入连接”“刷新连接列表”和“一键加入”等操作，建立连接后即可发送文本、发送文件，并实时查看当前连接信息、连接日志、已发送列表、文件接收列表和文本接收列表。页面重点用于同一网络环境下的 2 人直接互传，文件与文本内容不经过服务器，更适合重视传输效率和数据隐私的本地互传场景。

### 四、功能特点

1. 浏览器直接互传
2. 支持文本与文件
3. 创建连接与加入连接
4. 实时收发进度
5. 文件接收后可下载
6. 无需安装客户端

### 五、使用步骤

首次使用时建议两台设备同时打开本页，并按以下步骤完成连接建立和文件互传。当前页面无需填写设备标识，直接创建连接或加入连接即可开始使用。

1. 两台设备分别打开局域网文件传输工具，建议使用最新版 Chrome 或 Edge，以获得更稳定的使用体验。

2. 由其中一台设备点击“创建连接”，保持页面停留，等待当前连接出现在另一台设备的连接列表中。

3. 另一台设备点击“刷新连接列表”，选择目标连接后点击“一键加入”，等待页面提示连接成功即可开始传输。

4. 如果加入方看不到连接列表，请优先确认两台设备是否处于同一办公网络、同一路由器或同一 WiFi 环境下。

5. 连接成功后，可在“发送文件”和“发送文本”区域直接开始传输，页面会实时显示发送进度、接收进度和当前传输状态。

6. 接收完成后，文件会进入文件接收列表，文本会进入文本接收列表；你还可以查看连接日志和已发送列表，便于追踪整个传输过程。

### 六、适用场景

适合办公室电脑互传资料、同一网络下手机与电脑快速分享文件、测试包与安装包分发、演示现场传递文档，也适合不想通过聊天软件、网盘或第三方平台中转的本地设备文件交换场景。对于注重隐私的内部资料、截图、文本备注和压缩包互传，这类浏览器互传工具会更加直接高效。

1. 办公资料互传
2. 手机电脑传文件
3. 测试包快速分享
4. 局域网设备协作
